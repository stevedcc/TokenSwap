    inheritance) and grants only the current user `FullControl`, as `WindowsPrivateFolder.TryCreate` does for a
    folder; after creation the ACL is checked (current user only, not a reparse point) before the key is written;
    the same delete-on-failure.

    (`The vault was not created; delete {path}, it holds the recovery key of a vault that doesn't exist.`).
  - Accepted window: a kill between the key write and the vault write leaves a key file and no vault; harmless
    (it opens nothing), the user deletes it.
