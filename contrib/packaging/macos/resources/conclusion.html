tswap is installed in /usr/local/bin (tswap and its Secure Enclave library, libtswapse.dylib), for every user of this Mac.

To install the agent skill and the shell completions for your user, run in Terminal:

tswap installscript > installTswap.sh

review installTswap.sh, then run:

bash installTswap.sh

Run tswap from Terminal: it is a command-line tool.

To uninstall it later:

sudo rm /usr/local/bin/tswap /usr/local/bin/libtswapse.dylib
sudo pkgutil --forget dev.crawford.tswap.pkg

Your vault is never touched by installing or uninstalling. Details: docs/install.md in github.com/stevedcc/TokenSwap.
